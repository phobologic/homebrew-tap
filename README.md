# homebrew-tap

Personal [Homebrew](https://brew.sh) tap for tools by [@phobologic](https://github.com/phobologic).

## Usage

```sh
brew tap phobologic/tap
```

### Available formulae

| Formula | Description |
|---------|-------------|
| [permcop](https://github.com/phobologic/permcop) | A rule-based permission filter for Claude Code PreToolUse hooks |

Install with:

```sh
brew install phobologic/tap/permcop
```

### Available casks

| Cask | Description |
|------|-------------|
| [repoguide](https://github.com/phobologic/repoguide) | Generate tree-sitter repository maps in TOON format |

Install with:

```sh
brew install --cask phobologic/tap/repoguide
```

## Adding new formulae and casks

Formula definitions in `Formula/` and cask definitions in `Casks/` are auto-generated by [GoReleaser](https://goreleaser.com/) on release. Manual edits will be overwritten.
